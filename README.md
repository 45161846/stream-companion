# Stream Companion

Первая итерация: локальный прототип расширения Chrome с панелью внутри Twitch. Рекап, подборка моментов и объяснение контекста по одной записи **Recrent**. Данные и ответы подготовлены вручную; AI и сервер не подключены.

Модель разработки — **Iterative Enhancement**: эту версию развиваем дальше, заменяя источник ответов и добавляя возможности. Базовый стек — React + WXT; сервер на Python относится к следующему этапу.

## Запуск готовой сборки

1. Распаковать `output/extension/stream-companion-0.1.0-chrome.zip` в постоянную папку. В проекте уже есть распакованная сборка: `output/extension/chrome-mv3`.
2. В Chrome открыть `chrome://extensions`, включить «Режим разработчика» и нажать «Загрузить распакованное расширение».
3. Выбрать папку, в которой непосредственно находится `manifest.json`.
4. Открыть [подготовленную запись Recrent](https://www.twitch.tv/videos/2898815300). Если Twitch уже открыт, перезагрузить вкладку.

Панель встраивается рядом с основной областью страницы. Если видео слишком узкое, можно свернуть боковую навигацию или обычный Twitch-чат его штатной кнопкой. Расширение их не скрывает. Для страницы Twitch и видео нужен интернет; ответы не обращаются к внешнему сервису.

## Сценарий показа

- Нажать **«Краткий рекап»**: ответ про первые 30 минут и три события с источниками.
- Нажать **«Интересные моменты»**: карточки с таймкодами.
- Нажать **«Объясни контекст»**: объяснение экрана снаряжения, источник на 00:16:10. Открыть источник — он появляется в новой вкладке, диалог остаётся доступен.
- Попробовать свободный ввод: `Кратко перескажи начало` или `Объясни, что за инвентарь`. Затем спросить про другой период или неразмеченное событие — появится объяснение ограничений.
- Свернуть и снова открыть панель. Войти в fullscreen видео и выйти: панель скрывается и возвращается в прежнее состояние.
- Перейти к другой записи: вместо чата появляется предложение открыть подготовленную запись Recrent.
- Нажать **«Очистить чат»** для повторного показа.

## Границы первой итерации

Источник: [Recrent — «Крупнейшее обновление в ARC Raiders»](https://www.twitch.tv/videos/2898815300), запись 12 октября 2026 года, подготовленный диапазон **00:00:00–00:30:00**. На момент подготовки VOD был доступен публично и воспроизводился. Доступность внешнего VOD со временем может измениться.

Размечены три наблюдаемых момента: начало эфира (00:00:38), экран снаряжения (00:16:10), сцена с персонажем и обсуждение озвучки в чате (00:26:59). Это небольшой демонстрационный набор, а не полная расшифровка получасового фрагмента. Не приписываем стримеру неразмеченные реплики, результаты матчей или причины событий.

Поле ввода распознаёт ограниченный набор формулировок. Другие записи, периоды, смешные моменты, победы и произвольные вопросы не обслуживаются подготовленными ответами. Фиксированный рекап первых 30 минут не выдаётся за рекап относительно текущей позиции плеера.

История диалога хранится только в памяти вкладки. Перезагрузка, переход к другой записи или очистка чата её сбрасывают. Сворачивание панели и fullscreen сохраняют диалог. Аккаунты, сохранение переписки, обработка live, захват вкладки и внешние API в этой итерации отсутствуют.

## Разработка

Нужен Node.js 24 LTS и npm.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run zip
```

Сборка WXT: `.output/chrome-mv3`. `npm run dev` использует механизм WXT для запуска браузера разработки. Публикация в Chrome Web Store не выполнялась.

Основные файлы:

- `entrypoints/companion.content/index.tsx` — встраивание в Twitch, Shadow DOM и изоляция клавиатурных событий.
- `src/twitch/mount.tsx` — отслеживание смены страницы, fullscreen и жизненного цикла панели.
- `src/components/Panel.tsx` — чат, подсказки, очистка и сворачивание.
- `src/data/demo.ts` — запись Recrent, размеченные события и подсказки.
- `src/domain/types.ts` — контракт `AnswerProvider`.
- `src/domain/mock-provider.ts` — локальные ответы и проверка границ демо. Позже этот модуль можно заменить реализацией, обращающейся к серверу.

## Проверка

Автоматические проверки покрывают три сценария, источники и таймкоды, перефразировки, неподдерживаемые вопросы и периоды, смену записи, ошибки провайдера, отмену запроса при очистке, сворачивание и fullscreen.

Для визуальной проверки тех же компонентов есть внутренний стенд:

```sh
npm run preview
```

Открыть `http://localhost:5173`. Он содержит официальный плеер Twitch с той же записью и панель с тем же кодом. Кнопки под плеером переключают поддерживаемую/другую запись и позволяют проверить fullscreen. Это стенд компонентов; он не заменяет проверку установки расширения и интеграции с DOM настоящего Twitch в Chrome.

На текущем этапе сборка, TypeScript, 34 автоматических проверки и визуальные сценарии на стенде прошли. Реальный переход из ответа к VOD и таймкоду проверен во встроенном браузере. Chrome недоступен подключённым средствам управления, поэтому установка расширения и его компоновка на настоящей странице Twitch в Chrome **ещё не проверены**. Пилот, качество AI и требования полной версии продукта не проверялись.
